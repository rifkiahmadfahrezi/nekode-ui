<Callout type="warn">
  `ComboboxMultiField` is deprecated. Use [`<ComboboxField multiple />`](/docs/form-fields/combobox-field#multiple) instead. It is the same component with the same props, so migrating is a one-line change.
</Callout>

`ComboboxMultiField` used to be a separate component. Its chip-based multi select now lives inside `ComboboxField` behind the `multiple` prop, which gives you type-safe `value` / `onValueChange` from one component. `ComboboxMultiField` is now a thin alias that renders `<ComboboxField multiple />`, so nothing breaks if you already use it.

## Migration

```diff
- import { ComboboxMultiField } from "@/components/ui/combobox-multi-field";
+ import { ComboboxField } from "@/components/ui/combobox-field";

- <ComboboxMultiField
+ <ComboboxField
+   multiple
    options={options}
    value={values}
    onValueChange={setValues}
    overflow="hide"
  />
```

The type names map the same way:

| Old | New |
|---|---|
| `ComboboxMultiFieldProps` | `ComboboxFieldMultipleProps` (without `multiple`) |
| `ComboboxMultiFieldOption` | `ComboboxFieldOption` |

## API Reference

`ComboboxMultiField` accepts every [`ComboboxField`](/docs/form-fields/combobox-field#api-reference) prop for `multiple` mode (`value: string[]`, `onValueChange: (value: string[]) => void`, `overflow`, `showAllSelectedLabel`, ...), except `multiple` itself, which is always on.
