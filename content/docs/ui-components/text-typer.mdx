title: TextTyper

---

`TextTyper` reveals `text` character by character on a timer and restarts whenever `text` changes. It uses no animation library, only `setInterval` and state. Reach for it in hero headlines, empty states, or anywhere a line of copy should feel written live.

## Accessibility

- The visible, partially typed text and the caret are `aria-hidden="true"`. A visually hidden copy of the full `text` is what screen readers read, so they never hear half a word.
- Under `prefers-reduced-motion: reduce`, the full text shows immediately and `onComplete` fires right away.

## API Reference

### TextTyper

`TextTyper` also accepts every native `<span>` attribute except `children`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `text` | `string` | — | String to type out. Changing it restarts typing from the first character. Required. |
| `speed` | `number` | `50` | Milliseconds between characters. |
| `cursor` | `boolean` | `true` | Shows a blinking caret after the typed text. |
| `onComplete` | `() => void` | — | Called once the last character of the current `text` is shown. |
| `className` | `string` | — | Class name merged onto the root `<span>`. |
