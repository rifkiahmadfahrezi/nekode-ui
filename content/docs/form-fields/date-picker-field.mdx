`DatePickerField` wraps the shadcn `Calendar` and `Popover` components with the same `Field` layout as `TextField`: a label, an optional description, and error handling — all wired for accessibility out of the box. The popover header exposes native month and year `<select>` elements for fast navigation; `minDate`/`maxDate` constrain both the calendar days and the available month/year options.

## Accessibility

`DatePickerField` connects the label, description, and error message to the trigger button the same way `SelectField` does:

- The label uses `htmlFor`, so clicking it opens the calendar popover.
- `aria-describedby` points to the description, but only while there's no error.
- The error message is wired through `aria-errormessage` and `aria-invalid` flips to `true` whenever `error` is set.
- The calendar popover is keyboard-navigable through the underlying `DayPicker` and `Popover` primitives.

## API Reference

### DatePickerField

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Label rendered above (or beside) the trigger. |
| `description` | `string` | — | Helper text shown below the field. Hidden automatically when `error` is set. |
| `error` | `string` | — | Validation message. Switches the field into an invalid state. |
| `value` | `Date` | — | Controlled selected date. |
| `defaultValue` | `Date` | — | Initial date for uncontrolled use. |
| `onValueChange` | `(date: Date \| undefined) => void` | — | Fires when the user picks or clears a date. |
| `placeholder` | `string` | `"Pick a date"` | Text shown in the trigger when no date is selected. |
| `dateFormat` | `string` | `"PPP"` | A `date-fns` format string used to display the selected date. |
| `minDate` | `Date` | — | Earliest selectable date. Disables earlier days and filters month/year options. |
| `maxDate` | `Date` | — | Latest selectable date. Disables later days and filters month/year options. |
| `name` | `string` | — | Forwarded to the trigger button for native form submission. |
| `orientation` | `"vertical" \| "horizontal" \| "responsive"` | `"vertical"` | Layout direction for the label relative to the trigger. |
| `fieldClassName` | `string` | — | Class name passed to the underlying `Field` wrapper. |
| `labelClassName` | `string` | — | Class name applied to the `FieldLabel`. |
| `triggerClassName` | `string` | — | Class name applied to the popover trigger button. |
| `required` | `boolean` | `false` | Marks the field as required and adds the asterisk indicator. |
| `disabled` | `boolean` | `false` | Disables the trigger and dims the label. |
