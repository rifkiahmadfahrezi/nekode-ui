`ComboboxField` wraps Base UI's `Combobox` primitives with the same `Field` layout as `TextField`: a label, an optional description, and error handling in one piece. It behaves like `SelectField`, but the trigger is a real text input people can type into to filter `items`, plus a clear button and a `loading` state for when those items come from the network.

## Behavior

- **`items` is the full option list, not paged or async by itself.** `ComboboxField` filters client-side as the person types. If your options come from an API, fetch them yourself and pass `loading` while the request is in flight — the component doesn't fetch anything on its own.
- **`loading` forces the clear button off**, regardless of `showClear`, and replaces it with a spinner. The two aren't meant to share the space.
- **`loading` also disables the field**, same as `disabled` — there's no way to interact with a combobox while its options are still arriving.
- **The value is matched against `items` by `value`, not held as free text.** If `value` doesn't match any item's `value` (e.g. the list hasn't loaded yet), the input shows as empty rather than showing a stale label.

## Accessibility

`ComboboxField` connects the label, description, and error message to the input the same way `TextField` does:

- The label uses `htmlFor`, so clicking it focuses the input.
- `aria-describedby` points to the description, but only while there's no error, so screen readers don't hear a stale description read alongside an active error.
- The error message is wired through `aria-errormessage` instead, and `aria-invalid` flips to `true` whenever `error` is set.
- Combobox role, `aria-expanded`, active-descendant tracking, and keyboard navigation through the list all come from Base UI's `Combobox` primitive underneath — `ComboboxField` doesn't add or override any of it.

<Callout type="warn">
  The loading spinner is `aria-hidden`, and nothing else in the field announces the loading state to assistive tech. If a fetch can take more than a second or two, pair `loading` with your own visually-hidden live region (e.g. "Loading options…") so screen reader users aren't left wondering why the list is empty.
</Callout>

## API Reference

### ComboboxField

Like `SelectField`, `ComboboxField`'s props aren't a superset of a native HTML element's attributes — the component only accepts the props listed below.

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Label rendered above (or beside) the input. |
| `description` | `string` | — | Helper text shown below the input. Hidden automatically when `error` is set. |
| `error` | `string` | — | Validation message. Switches the field into an invalid state and renders through `FieldError`. |
| `placeholder` | `string` | `"Select an option"` | Shown in the input when no value is selected. |
| `emptyText` | `string` | `"No results found."` | Shown in the list when filtering matches nothing. |
| `options` | `ComboboxFieldOption[]` | — | **Required.** The full list of selectable options. |
| `value` | `string` | — | Controlled value, matched against `options` by `value`. |
| `onValueChange` | `(value: string \| undefined) => void` | — | Fires with the selected item's value, or `undefined` when cleared. |
| `name` | `string` | — | Forwarded to the underlying input, for native form submission. |
| `loading` | `boolean` | `false` | Shows a spinner in place of the clear button and disables the field. Use while `items` is being fetched. |
| `showClear` | `boolean` | `true` | Shows a clear ("×") button once a value is selected. Forced off while `loading`. |
| `autoHighlight` | `boolean` | `false` | Auto-highlights the first matching item while filtering. |
| `orientation` | `"vertical" \| "horizontal" \| "responsive"` | `"vertical"` | Layout direction for the label relative to the input. |
| `fieldClassName` | `string` | — | Class name passed to the underlying `Field` wrapper. |
| `labelClassName` | `string` | — | Class name applied to the `FieldLabel`. |
| `inputClassName` | `string` | — | Class name applied to the `ComboboxInput`. |
| `required` | `boolean` | `false` | Marks the field as required and adds the asterisk indicator. |
| `disabled` | `boolean` | `false` | Disables the field and dims the label. |

### ComboboxFieldOption

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Text shown in the option list and matched while filtering. |
| `value` | `string` | — | Value passed to `onValueChange` when selected. |
| `disabled` | `boolean` | `false` | Prevents this option from being selected. |
