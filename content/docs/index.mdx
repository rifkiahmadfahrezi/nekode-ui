nekode/ui extends [shadcn/ui](https://ui.shadcn.com) components make it simpler and easier to use. copy-paste into your project, same as shadcn itself.

<Cards>

  <Card title="Form Fields" description="Text, number, password, select, combobox, date picker, time picker, textarea." href="/docs/form-fields/text-field" />
</Cards>

## Installation

Install components with the shadcn CLI, pointed at this registry:

<InstallationTabs componentName="datatable" />

Each component's docs page has the exact command for that component under Installation.

<Callout type="info">
  Components are built on shadcn/ui's **Base UI** backend (`@base-ui/react`), not Radix. If you're used to Radix-based shadcn components, check each page's callouts for the differences that carry through the API.
</Callout>
